Key Remediation Recommendations
1. Implement MFA and Least-Privilege IAM (A.5.15 + A.5.17)
Unauthorised access to the learner database is the highest-scored risk at 20. MFA across all AWS accounts and IAM least-privilege enforcement must be completed within 7 days before any partner onboarding.
PHASE 1 // 0–7 DAYS // CRITICAL
2. Enable AWS GuardDuty and Patch All EC2 Instances (A.8.7)
Ransomware risk scored 20. GuardDuty activation and a full EC2 patch cycle must be completed immediately. Unpatched infrastructure is the primary attack vector for cloud ransomware campaigns.
PHASE 1 // 0–14 DAYS // CRITICAL
3. Deploy CloudTrail and CloudWatch Logging (A.8.15 + A.8.16)
No logging is currently enabled across AWS regions. CloudTrail and CloudWatch must be configured to provide audit trail coverage. Without this, incident detection and forensic investigation are impossible.
PHASE 2 // 30–60 DAYS // HIGH
4. Complete Vendor Security Questionnaires and DPAs (A.5.19)
Third-party vendors with access to learner PII have not been formally assessed. Data Processing Agreements and vendor security questionnaires must be completed before partner onboarding proceeds.
PHASE 3 // 60–90 DAYS // HIGH
